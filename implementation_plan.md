# Implementation Plan: Resume to Job Application Agent (3-Person Team Breakdown)

Create a local prototype of a resume builder, optimizer, job application agent, and email alert system using a **mixed hierarchical agent architecture** built on the **Google Agent Development Kit (ADK)**, **Streamlit** (frontend), **Playwright** (browser automation), and **smtplib** (email notifications).

## Team Role Breakdown (3-Person Team)

To efficiently execute the implementation, the tasks are divided into three parallel work streams:

### 👤 Developer 1: Streamlit Frontend & Integration
- **Primary Focus**: User interface, configuration forms, interactive state visualization, and human-in-the-loop (HITL) communication.
- **Key Tasks**:
  1. Build the Streamlit multi-tab structure.
  2. Implement manual resume data entry forms and file upload widgets (resume upload, example layout upload).
  3. Create the simplified Job Alerts UI (Recipient Email, Role Search, Location) and a collapsible Advanced Settings SMTP panel (pre-filled with dummy/showcase credentials).
  4. Build the HITL notification panel: displays paused form-filling questions, collects answers, and updates the shared JSON state.
  5. Implement the logged applications history dashboard.

### 👤 Developer 2: Agent Logic, Scrapers & Email Service
- **Primary Focus**: ADK agent definitions, LLM-as-a-judge scoring, 24-hour job scraping, and SMTP mailer.
- **Key Tasks**:
  1. Define the parent Coordinator Agent (pre-flight gatekeeper guardrail) and configure the ADK subagents registry.
  2. Implement the ATS Analyzer Agent's LLM prompt instructions (scoring 0-100, gap analysis, recommendations).
  3. Build the Playwright LinkedIn 24-hour Job Scraper tool.
  4. Set up the SMTP Mailer service using standard `smtplib` to compile and send styled HTML emails, supporting default/dummy credentials loaded from environment files when user overrides are not provided.
  5. Implement the standalone scheduler script (`daily_job_alerts.py`) and write `pytest` unit tests for parsing and emailing.

### 👤 Developer 3: Form Filling & Resume Export Engine
- **Primary Focus**: Playwright form-filling automation, redirect handlers, and PDF/Docx generators.
- **Key Tasks**:
  1. Develop the Form Filler Agent's Playwright tool to navigate applications, follow redirects to external portals (Workday, Greenhouse, Lever, etc.), map resume data to both LinkedIn Easy Apply forms and external forms, and upload the resume.
  2. Implement the HITL pause-and-resume mechanism inside Playwright (listening to the shared JSON state file).
  3. Build the HTML-to-PDF generator utilizing Playwright's PDF printing.
  4. Create the Word Document (`.docx`) template generator using `python-docx`.
  5. Implement the visual style copying logic (mapping PDF/Docx structure and HTML CSS styling to output files).

### Hierarchical Agent Logic & Guardrails (ADK App)

#### [NEW] [app/agent.py](file:///C:/Users/sathw/Downloads/googlexkaggle_course/test_cap_project/app/agent.py)
- **Coordinator Agent (Parent)**: Acts as the main entry point. Uses LLM Pre-flight Gatekeeper logic to inspect prompts for off-topic content. Routes career-related inputs to target subagents using ADK `sub_agents` delegation.
- **ATS Analyzer Agent (Subagent)**: Analyzes job descriptions, calculates 0-100 fit score, and lists gaps.
- **Resume Builder Agent (Subagent)**: Customizes resumes and handles content generation. Emulates visual layout structures (like 2-column list) and style elements from upload templates.
- **Job Alerts Agent (Subagent)**: Manages 24-hour job scraping and alert emails.
- **Form Filler Agent (Subagent)**: Triggers Playwright automations, pauses for human responses to unknown fields, and uploads resumes.
- Instructions strictly define truthfulness rules to prevent hallucination.

#### [NEW] [app/tools.py](file:///C:/Users/sathw/Downloads/googlexkaggle_course/test_cap_project/app/tools.py)
- Implements:
  - **Resume Parser**: Extract text from PDF (`pypdf`), Word (`docx`), or text.
  - **ATS Evaluator**: Details gaps and scores.
  - **LinkedIn Job Scraper**: Searches LinkedIn via Playwright using persistent session cookies stored in `playwright_session/` to fetch jobs posted in the last 24 hours.
  - **Playwright Form Filler**:
    - Scrapes target job description from URL (and handles redirects from LinkedIn external links).
    - Fills Greenhouse/Lever/Workday/LinkedIn forms.
    - Pauses execution and communicates unknown questions to Streamlit via a shared JSON state.
    - Uploads the generated PDF resume.
    - Pauses before the final "Submit" button.
  - **Local Logger**: Logs submitted applications to `applications_log.json`.
